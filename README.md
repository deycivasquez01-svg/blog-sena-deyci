https://deycivasquez01-svg.github.io/blog-sena-deyci/

## Publish
1. Upload `index.html`, `styles.css`, `script.js` and the `assets` folder to the repository.
2. GitHub > Settings > Pages.
3. Under Build and deployment choose `Deploy from a branch`.
4. Branch: `main`; folder: `/ (root)`.
5. Save.
6. Wait a few minutes and open the URL above.

The two YouTube videos are already embedded in `index.html`.
